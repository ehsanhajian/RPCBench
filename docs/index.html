RPCBench

Which RPC endpoint is fastest — for this call, from this machine? A vendor-neutral CLI that compares JSON-RPC and REST providers on latency, P50/P95/P99, error rate, and freshness.

Quick start pip install rpcbench GitHub

Three tools, one job each

RPCBench Benchmark quality from your machine. Pick a primary and a fallback.
Nodeprobe Security / surface scan of an RPC. Not latency ranking.
ValidatorPulse Always-on validator monitoring. Not a one-shot compare.

Install

pip install rpcbench
rpcbench compare --endpoints endpoints.yaml

Python 3.10+. Read-only by default. No accounts. No telemetry. Localhost and private URLs are allowed so you can bench your own node. Details and flags live in the README.

What you get

  • EVM, Solana, Substrate, Cosmos, Aptos, Sui, NEAR, Starknet, Bitcoin, TON
  • Paired compare, similar-band ranking, freshness / lag, HTML + JSON + Prometheus
  • Live TUI and optional --web UI; Docker image and GitHub Action for CI SLOs
